# Controls

Every command is in the menu bar (File, Edit, Track, Transport, View, Help) and in the command menu (`⌘K`, `Ctrl+K`): type part of its name and press Return. **Help ▸ Keyboard Shortcuts** (`⌘/`, `Ctrl+/`) lists the shortcuts below inside the app. Right-clicking a clip, a lane, a track's header, the ruler, the chord track, a note, a mixer strip or anything in the browser shows what can be done to it.

Plain keys (Space, `Q`, `R`, the arrows) wait while a text field has the focus, and the letters wait while the piano roll has it, because they play notes there.

## Keyboard shortcuts

### File

| Command | macOS | Windows and Linux | What it does |
| --- | --- | --- | --- |
| Save | `⌘S` | `Ctrl+S` | Save the project in its folder; the first save asks where. |
| Save As | `⇧⌘S` | `Ctrl+Shift+S` | Save a copy of the project in a new folder, with its takes. |
| Export as MIDI File | `⌘E` | `Ctrl+E` | Save the project as a MIDI file. |
| Export as Audio File | `⌘B` | `Ctrl+B` | Render the mix, or each track, to WAV. |
| New | `⌘N` | `Ctrl+N` | Start a new project: 120 bpm, 4/4, drums and a piano. |
| Open | `⌘O` | `Ctrl+O` | Open a project folder, or its project.json. |

### Edit

| Command | macOS | Windows and Linux | What it does |
| --- | --- | --- | --- |
| Undo | `⌘Z` | `Ctrl+Z` | Take back the last change. |
| Redo | `⇧⌘Z` | `Ctrl+Shift+Z` | Do again the change you took back. |
| Cut | `⌘X` | `Ctrl+X` | Copy the selected notes or clip, then delete them. |
| Copy | `⌘C` | `Ctrl+C` | Copy the selected notes or clip. |
| Paste | `⌘V` | `Ctrl+V` | Paste at the playhead, on the selected track. |
| Duplicate | `⌘D` | `Ctrl+D` | Put a copy of the selected notes or clip right after them. |
| Delete | `⌫` (or `⌦`) | `Backspace` (or `Delete`) | Delete the selected notes, clip or chords. |
| Select All | `⌘A` | `Ctrl+A` | Select every note in the piano roll. |
| Deselect All | `⎋` | `Esc` | Select no notes, clip or chords. |
| Split at Playhead | `⌘T` | `Ctrl+T` | Cut the clips under the playhead in two. |
| Join with Next Clip | `⌘J` | `Ctrl+J` | Make the selected clip and the one after it one clip. |
| Quantize | `Q` | `Q` | Move the selected notes, or the clip’s, onto the grid. |
| Transpose Up | `↑` | `Up` | Move the selected notes up a semitone. |
| Transpose Down | `↓` | `Down` | Move the selected notes down a semitone. |
| Octave Up | `⇧↑` | `Shift+Up` | Move the selected notes up an octave. |
| Octave Down | `⇧↓` | `Shift+Down` | Move the selected notes down an octave. |
| Nudge Left | `←` | `Left` | Move the selected notes back a grid step, or the clip a bar. |
| Nudge Right | `→` | `Right` | Move the selected notes on a grid step, or the clip a bar. |
| Mute Clip | `M` | `M` | Silence the selected clip, or play it again. |
| Make Pattern | `⌘P` | `Ctrl+P` | Make the selected clip a pattern, so its copies stay linked. |

### Track

| Command | macOS | Windows and Linux | What it does |
| --- | --- | --- | --- |
| New Track | `⌥⌘N` | `Ctrl+Alt+N` | Add an instrument track below the selected one. |
| Duplicate Track | `⇧⌘D` | `Ctrl+Shift+D` | Add a copy of the selected track, with its clips. |
| Delete Track | `⌘⌫` | `Ctrl+Backspace` | Delete the selected track and its clips. |
| Move Track Up | `⌥⌘↑` | `Ctrl+Alt+Up` | Move the selected track up the list. |
| Move Track Down | `⌥⌘↓` | `Ctrl+Alt+Down` | Move the selected track down the list. |

### Transport

| Command | macOS | Windows and Linux | What it does |
| --- | --- | --- | --- |
| Play or Stop | `Space` | `Space` | Start or stop playing from the playhead. |
| Record | `R` | `R` | Record a melody on the selected track, or a chord on the chord track. |
| Go to Start | `↩` | `Enter` | Move the playhead to the start (of the loop, while it plays). |
| Go to End | `↘` | `End` | Move the playhead to the end of the project. |
| Back a Bar | `,` | `,` | Move the playhead back a bar. |
| Forward a Bar | `.` | `.` | Move the playhead on a bar. |
| Previous Marker | `⌥,` | `Alt+,` | Move the playhead to the marker before it. |
| Next Marker | `⌥.` | `Alt+.` | Move the playhead to the next marker. |
| Loop | `C` | `C` | Loop the selection, or the section at the playhead; again turns it off. |
| Loop Selection | `⌘U` | `Ctrl+U` | Move the loop to the selection. |

### View

| Command | macOS | Windows and Linux | What it does |
| --- | --- | --- | --- |
| Browser | `B` | `B` | Show or hide the browser of instruments, kits, projects and takes. |
| Piano Roll | `⌘1` | `Ctrl+1` | Show the piano roll in the editor. |
| Mixer | `⌘2` | `Ctrl+2` | Show the mixer in the editor. |
| Step Grid | `⌘3` | `Ctrl+3` | Show the drum step grid in the editor. |
| Zoom In | `⌘=` (or `⌘+`) | `Ctrl+=` (or `Ctrl++`) | Show less time, larger. |
| Zoom Out | `⌘-` | `Ctrl+-` | Show more time, smaller. |
| Zoom to Fit | `⌘0` | `Ctrl+0` | Fit the whole project in the arrangement. |
| Command Menu | `⌘K` | `Ctrl+K` | Find any command by name and run it. |

### Help

| Command | macOS | Windows and Linux | What it does |
| --- | --- | --- | --- |
| Keyboard Shortcuts | `⌘/` | `Ctrl+/` | List every command with its shortcut. |

## Other keys

| What | Keys |
| --- | --- |
| Play the selected track's instrument (click the piano roll first; while it has the focus, `B`, `C`, `M`, `Q` and `R` wait until you click elsewhere, or use the menus) | `A S D F G H J K L ; '` white keys, `W E T Y U O P` black keys |
| An octave down or up, while playing it | `Z`, `X` |
| Move through the command menu's list, run the command, close it | `↑` `↓` or `Tab` `Shift Tab`, `Return`, `Esc` |
| Draw a note without the grid | `Alt` while drawing |
| Copy a clip as you drag it | `Alt` drag |
| Zoom with the scroll wheel | `Cmd` + scroll (`Ctrl` + scroll on Windows and Linux) |

## Mouse and MIDI

| What | How |
| --- | --- |
| Play and stop | **▶** and **■**; **■** twice goes back to the start |
| Move the playhead | click the ruler |
| Metronome | **♩** |
| New, save, save as | **New**, **Save**, **Save as** |
| Import a MIDI file as a new project, or drop one on a track to add its tracks from that bar | File ▸ Import MIDI File…, or drag it in |
| Paste where you clicked | right-click, **Paste Here** |
| Loop | drag along the ruler; right-click a clip, a marker or the ruler |
| Record a melody (whistled, or played on the keys or a MIDI keyboard) | **●** |
| Set a chord | drag over the chord track, then `R` and whistle its notes |
| Draw a note | click empty space in the piano roll |
| Move or resize a note | drag it, or drag its right edge |
| Select notes | `Shift` click adds or removes one, `Shift` drag on empty space adds a rectangle of them |
| Humanize, double or half speed, reverse, transpose, velocity, legato | right-click the notes or the clip |
| Move or copy a clip | drag it; `Alt` drag copies it |
| Split a clip where you clicked | right-click, **Split Here** |
| Insert or delete bars, add a marker, change the tempo or meter from a bar on (a flag on the ruler shows each change) | right-click the ruler; right-click or double-click a flag to edit it, ramp to the next tempo, or remove it |
| New, duplicate, rename, colour or delete a track; move it | right-click its header; drag the header |
| Draw an empty clip (on a drum track, a new pattern) | double-click a track's lane |
| Make a clip a pattern, so its copies stay linked; make one copy unique again; rename the pattern | right-click the clip |
| Turn drum steps on or off | click a step in the step grid, drag to paint; `Shift` click accents a step |
| Step size of a drum clip (1/8, 1/16, 1/32, 1/16 triplet) | the step grid's **Step** menu |
| Add or hide a drum row | right-click a row in the step grid, **Add Row**, **Hide** |
| Put an instrument on a track | click it in the browser's Instruments tab, or drag it onto the track |
| Play notes from a MIDI keyboard | plug it in; its sustain pedal works too |
